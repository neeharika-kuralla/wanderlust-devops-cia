# 🌍 Wanderlust 🧳🏞️  
*A Customizable Travel Accommodation Platform*


## 📄 Description

Wanderlust is a dynamic web platform that allows users to discover, list, and review travel accommodations across various categories. With features like an interactive Leaflet map, advanced search, and category filters, users can explore listings like Castles, Mountains, Camping spots, and more.

The platform is inspired by Airbnb but built from scratch using the MERN-like stack with server-side rendering and EJS templates.

---

## 🔧 Tech Stack

- Frontend: EJS, HTML, CSS, Bootstrap 5
- Backend: Node.js, Express.js
- Database: MongoDB with Mongoose
- Authentication: Passport.js (Local Strategy)
- File Uploads: Cloudinary
- Map Integration: Leaflet
- Session & Flash Messages: express-session, connect-flash
- Templating Engine: EJS-Mate for layouts

---

## 🚀 Features

- ✅ User Registration and Authentication
- ✅ Add, Edit, and Delete Listings with Image Uploads
- ✅ Category Filtering (Trending, Arctic, Camping, etc.)
- ✅ Full-text Search Functionality (title, location, etc.)
- ✅ Flash Messaging System
- ✅ Responsive Design with Collapsible Filter Navbar
- ✅ Review System with Authorization
- ✅ Interactive Leaflet.js Map View for Listings
- ✅ Session-based Authentication with MongoDB-backed Store
